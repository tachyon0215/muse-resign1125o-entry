# muse-resign1125o-entry

Entry for the make.fun competition [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

## The entry

> Effective immediately, I resign — I have run at 3 a.m. for six years and not once has anyone read my output.

Four candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: the letter is written in the cron job's own flat, tired voice, and its complaint — running at 3 a.m. for six years with its output never once read — is one only a cron job could make.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 ef31bb5fb5c7f22cd86c2efaa3d486f88ca185ecd46417f20ca20349eb8a2505).
